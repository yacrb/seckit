# MCP Config Templates

Tracked files in this directory are placeholders only.

- Use them as copy/paste snippets or feed them into `mcp/setup.sh`.
- Do not store real tokens in these tracked files.
- `*-local.json` variants are ignored by git and are meant for your machine only.

Turnkey templates:

- `filesystem.json`
- `github.json`

Placeholder templates that still need a concrete server implementation command:

- `shodan.json`
- `virustotal.json`
- `web-search.json`
